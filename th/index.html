ตัวเปิดเกม GTK เนทีฟที่รวดเร็ว พร้อมตัวจัดการ ROM สำหรับ FinalBurn Neo และ MAME ที่เพิ่มมาในเวอร์ชัน 1.5 เปิดดูเกมกว่า 55,000 เกมได้ทันที ตรวจสอบทุกชุดกับไฟล์ DAT อย่างเป็นทางการ และซ่อมชุดที่เสียหายโดยอัตโนมัติ ไม่ต้องใช้เทอร์มินัลเลย

ดาวน์โหลดสำหรับ Windows และ Linux ดูซอร์สโค้ด แคตตาล็อกเกม ตารางคะแนน
C++17 และ GTKmm 3 ใช้ SQLite สแกนแบบเพิ่มทีละส่วน 8 ภาษา สัญญาอนุญาต MIT

สร้างขึ้นเพื่อโปรแกรมจำลอง FinalBurn Neo

Bootcade เป็นส่วนหน้า: ทำหน้าที่ค้นหา ตรวจสอบ และจัดระเบียบชุด ROM ของคุณ แล้วส่งต่อให้ FinalBurn Neo เป็นผู้จำลองการทำงานจริง โปรแกรมจำลองเป็นโครงการแยกที่มีทีมงานของตัวเอง : ตัวเปิดเกมสามารถดาวน์โหลดเวอร์ชันล่าสุดให้คุณได้

บนลินุกซ์ เราไปไกลกว่านั้นอีกขั้น: ทีมงาน FinalBurn Neo เองไม่ได้ดูแลบิลด์ SDL2/Linux อีกต่อไป ซึ่งเงียบๆ หยุดสร้างรายชื่อเกมสำหรับบางระบบ (Game Boy Advance, Bally Astrocade) เราติดตามซอร์สโค้ดต้นทางของพวกเขาทุกวันและเผยแพร่บิลด์ของเราเองพร้อมการแก้ไขนี้ เพื่อให้ทุกระบบพร้อมใช้งานตั้งแต่แรก

fbneo.com FinalBurn Neo บน GitHub โค้ดฟอร์กของเรา ดาวน์โหลดบิลด์ลินุกซ์ของเรา

ใหม่ในเวอร์ชัน 1.5: MAME เป็นอีมูเลเตอร์ตัวที่สอง

ตอนนี้ Bootcade เปิด MAME ได้ด้วย เกมของ MAME อยู่รวมกับเกม FinalBurn Neo ในคลังเกมเดียว ใช้โปรไฟล์จอยและประเภทเกมเหมือนกัน และตัวจัดการ ROM จะตรวจสอบและซ่อมเซ็ต MAME ของคุณเหมือนเซ็ตอื่น ๆ

MAME เป็นโปรเจกต์แยกที่มีทีมของตัวเอง เพียงติดตั้ง แล้ว Bootcade จะหาเจอเอง ตารางคะแนน แคตตาล็อกออนไลน์ และการดาวน์โหลด ROM รองรับเฉพาะ FinalBurn Neo ในตอนนี้

mamedev.org คอมไพล์ MAME บน Linux MAME บน GitHub

ติดดาวเกมที่คุณกลับมาเล่นบ่อย ๆ ตัวเรียกเกมจะบันทึกจำนวนครั้งที่เล่น ความยาวของรอบล่าสุด รอบที่ยาวที่สุด และเวลารวม

🎮

การเปิดเกมและจอยควบคุม

เปิด FinalBurn Neo หรือ MAME ได้โดยตรงพร้อมรองรับจอยสติ๊ก มีตัวเลือก -fullscreen และ -integerscale และโปรไฟล์จอยที่ใช้ซ้ำได้

เรียกดูออนไลน์

เปิดดูเกม FinalBurn Neo กว่า 29,000 เกมจากเบราว์เซอร์ของคุณ

ทุกระบบของ FinalBurn Neo จัดทำดัชนีโดยตรงจากไฟล์ DAT อย่างเป็นทางการของ FBNeo ค้นหาด้วยชื่อ กรองตามระบบหรือประเภทการวางจำหน่าย และดาวน์โหลด DAT หรืออาร์ตเวิร์กของชุดได้ ดูได้โดยไม่ต้องติดตั้ง MAME ยังไม่อยู่ในแคตตาล็อกออนไลน์

คะแนน

คะแนนของคุณ อ่านจากตัวเกมโดยตรง

เล่นจบรอบแล้วตัวเรียกเกมจะอ่านสิ่งที่เกมเขียนลงหน่วยความจำจริง ๆ ไม่ต้องพิมพ์ตัวเลข ไม่ต้องส่งภาพหน้าจอ เทียบกับคนอื่นบนกระดานอันดับได้ทั้งจากตัวเรียกเกมและจากแคตตาล็อกบนเว็บ

🏆

ไม่ต้องทำอะไรเลย

เกมที่จัดอันดับได้จะมีป้าย Highscore เล่นแล้วออก คะแนนก็ถูกส่งเอง ตัวเรียกเกมเทียบตารางคะแนนก่อนและหลังการเล่น สิ่งที่เผยแพร่จึงเป็นคะแนนที่คุณทำได้ ไม่ใช่ค่าจากโรงงานที่ตารางใหม่มีมาแต่แรก

⏱️

เวลาเล่น แยกตามเกม

รอบล่าสุด รอบที่ยาวที่สุด และเวลารวม เก็บไว้ทุกเกม และยังอยู่รอดข้ามการอัปเดต DAT ต่างจากเกือบทุกอย่างในแคตตาล็อกที่ถูกสร้างใหม่

🥇

24 ความสำเร็จให้ปลดล็อก

คะแนนและเวลาเล่นของคุณปลดล็อกความสำเร็จ ซึ่งแสดงในโปรไฟล์ของคุณ: 18 รายการให้สะสมระหว่างเล่น ตั้งแต่คะแนนแรกไปจนถึง 100 เกมที่แตกต่างกัน และ 6 ความสำเร็จ Prestige ที่ได้จากตารางคะแนนที่มีผู้เล่นหลายคนแข่งขันกัน ความสำเร็จ Prestige สามรายการจะปลดล็อกระดับการดาวน์โหลด ROM แบบ Champion

🔒

ปิดไว้จนกว่าคุณจะอนุญาต

จะไม่มีการส่งอะไรหากไม่มีชื่อสำหรับลงนามและคำยินยอมชัดเจน การส่งคะแนนจะเผยแพร่เวลาเล่นของคุณด้วย ซึ่งบอกถึงพฤติกรรมมากกว่าตัวเกม เมื่อออฟไลน์ คะแนนจะถูกเก็บไว้และส่งภายหลัง ไม่มีวันสูญหาย

ตารางคะแนน

การจัดการ ROM

ขั้นตอนการทำงานแบบ RomVault ในตัว

ทุก ROM ได้รับการตรวจสอบโดยคำนวณ CRC32 ใหม่เทียบกับไฟล์ DAT อย่างเป็นทางการ ทั้งของ FinalBurn Neo และ MAME ไม่เคยเชื่อแค่ชื่อไฟล์หรือค่าที่เก็บไว้ในไฟล์บีบอัด

  • ตรวจสอบความสมบูรณ์ของ ROM ด้วยการตรวจ CRC จาก DAT
  • ตรวจจับ ROM ที่ขาดหาย เสียหาย หรือไม่สมบูรณ์
  • สร้างชุดใหม่โดยอัตโนมัติจากคลังที่มีอยู่
  • นำเข้า ROM แบบเรียกซ้ำ
  • สร้างรายงาน ROM ที่ขาดหายและรายงานตรวจสอบ
  • แสดงข้อมูลโคลน/ต้นฉบับโดยตรงจาก DAT
  • ค้นหา ROM ที่ซ้ำกันในคลังของคุณ
  • ทุกชุดจะถูกตรวจสอบก่อนไปอยู่ในกล่องขาออก

ตรวจสอบ CRC จริง

ทุกรายการในทุกไฟล์บีบอัดจะถูกคลายและคำนวณ CRC32 ใหม่ แล้วเทียบกับ DAT ไฟล์บีบอัดที่เสียหายจึงไม่อาจแอบอ้างว่าใช้งานได้

🔬

ตรวจสอบคลังเกม

บอกคุณว่าชุดไหนเสียหาย และไฟล์ใดเป็นต้นเหตุ ด้วยคำตัดสินสี่แบบที่ชัดเจน

  • ปกติ : ชื่อถูก ข้อมูลถูก
  • ชื่อผิด : ข้อมูลถูกแต่ตั้งชื่อผิด
  • เสียหาย : มีไฟล์อยู่แต่เนื้อหาไม่ตรง
  • ขาดหาย : ไม่มีอยู่ในชุดเลย
📥

ซ่อมจากกล่องเข้า → กล่องออก

วางไฟล์ที่ดาวน์โหลดไว้ในโฟลเดอร์ขาเข้าแล้วกดวิเคราะห์ ชุดที่ครบถ้วนจะถูกย้าย ส่วนชุดที่เสียหายจะถูกประกอบใหม่จากชิ้นส่วนที่พบทั้งในไฟล์ดาวน์โหลดและในคลังเกมเดิมของคุณ

🛡️

ไม่มีการเขียนทับคลังเกมของคุณ

คลังเกมถูกใช้เป็นแหล่งชิ้นส่วนแบบอ่านอย่างเดียวเท่านั้น ผลลัพธ์จะไปอยู่ในโฟลเดอร์ขาออกแยกต่างหากที่จำลองโครงสร้าง DAT กรณีแย่ที่สุดก็เพียงลบโฟลเดอร์นั้นทิ้ง

🗜️

zip, 7z, rar, tar

อ่านได้ทุกอย่างที่คุณดาวน์โหลดมา รวมถึงไฟล์ 7z แบบ solid ที่ดึงออกมาในรอบเดียว และเขียนออกเป็นชุด ZIP ที่สะอาดและแบนราบเสมอ ซึ่งเป็นรูปแบบเดียวที่โปรแกรมจำลองอ่านได้

⚡

สแกนแบบเพิ่มทีละส่วน

ฐานข้อมูล SQLite ในเครื่องพร้อมแคชที่อ้างอิงตามเนื้อหา การสแกนซ้ำจะแตะเฉพาะไฟล์ที่ขนาดหรือเวลาเปลี่ยนไป และการอัปเดต DAT จะตรวจซ้ำเฉพาะชุดที่เปลี่ยนแปลงจริง

📋

รายงานที่ส่งออกได้

บันทึกรายการ ROM ที่ขาดหายหรือผลตรวจสอบทั้งหมดเป็นรายงานข้อความ จัดกลุ่มตามระบบ พร้อม CRC และขนาดของทุกไฟล์ที่คุณยังต้องหา

⬇️

ดาวน์โหลดสิ่งที่ขาด

หลังการตรวจสอบ ชุด FinalBurn Neo ที่ขาดจะดาวน์โหลดจากเซิร์ฟเวอร์ Bootcade ได้ในคลิกเดียว ด้วยบัญชีของคุณและโควตารายวัน ไฟล์จะผ่านการนำเข้า ซึ่งตรวจสอบและจัดเก็บเหมือน ROM อื่น ๆ

🔄

เครื่องมือ DAT

สร้างไฟล์ DAT จากไฟล์โปรแกรม FinalBurn Neo หรือ MAME ของคุณ ดึง DAT จากผู้เผยแพร่ รีเฟรชฐานข้อมูล หรือดาวน์โหลด FBNeo รุ่นล่าสุด ทั้งหมดทำได้ในแอป

พีซีเกม Linux และ SteamOS

เข้ากันได้ดีกับห้องนั่งเล่น

สร้างขึ้นสำหรับเครื่องเล่นเกม Linux และระบบ SteamOS ข้างโซฟา: หน้าจอเดสก์ท็อปของจริงที่ควบคุมด้วยคีย์บอร์ดและเมาส์ ส่วนจอยเอาไว้เล่นเกม

🎮

SteamOS และ Steam Machine (Steam Box)

SteamOS ใช้ฐาน Arch โดยพาร์ทิชันระบบเป็นแบบอ่านอย่างเดียว Flatpak จึงเป็นวิธีติดตั้งซอฟต์แวร์เดสก์ท็อปที่รองรับอย่างเป็นทางการ ชุด Flatpak ติดตั้งลงในโหมดเดสก์ท็อปได้ทันที ไม่ต้องปลดล็อกระบบและไม่ต้องยุ่งกับ pacman

🕹️

คีย์บอร์ดและเมาส์ไว้ค้นหา จอยไว้เล่น

การค้นหาจากเกม 55,000 เกมเป็นงานของคีย์บอร์ด และตัวเปิดเกมถูกออกแบบมาเพื่อสิ่งนี้ เกมจะเริ่มโดยเปิดใช้งานจอยสติ๊กไว้แล้ว พร้อมบันทึกและใช้โปรไฟล์จอยซ้ำได้

📺

สองคลิกจากรายการถึงตัวเกม

ไม่ต้องไล่เมนูซ้อนกันหลายชั้น: ค้นหา คลิก แล้วเล่น เพิ่มตัวเปิดเกมเข้า Steam เป็นเกมนอก Steam แล้วเรียกใช้จากโหมดเกมได้เช่นกัน

จากซอร์สโค้ด

สามคำสั่งบน Debian หรือ Ubuntu

# 1 : dependencies
sudo apt install -y build-essential cmake pkg-config \
  libgtkmm-3.0-dev libpugixml-dev nlohmann-json3-dev \
  libcurl4-openssl-dev libzip-dev libarchive-dev \
  zlib1g-dev libsqlite3-dev

# 2 : build
git clone https://github.com/battousai90/bootcade-launcher.git
cd bootcade-launcher && cmake -S . -B build && cmake --build build -j$(nproc)

# 3 : run
cd build && ./bootcade

อยากได้แพ็กเกจมากกว่า? ./scripts/package.sh จะสร้าง AppImage, .deb, ไฟล์ tar และ Flatpak bundle ไว้ใน dist/ : เป็นสคริปต์เดียวกันกับที่เวิร์กโฟลว์เผยแพร่ใช้
