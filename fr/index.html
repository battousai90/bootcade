Conçu pour l'émulateur FinalBurn Neo

Bootcade est une interface : il trouve, vérifie et organise vos sets de ROMs, puis les confie à FinalBurn Neo, qui se charge de l'émulation. L'émulateur est un projet distinct avec sa propre équipe : le lanceur peut en télécharger la dernière version pour vous.

Sous Linux, on va un peu plus loin : l'équipe de FinalBurn Neo ne maintient plus la version SDL2/Linux, qui avait cessé en silence de générer les listes de jeux pour certains systèmes (Game Boy Advance, Bally Astrocade). On suit leur dépôt au quotidien et on publie notre propre build avec ce correctif, pour que tous les systèmes soient couverts d'office.

fbneo.com FinalBurn Neo sur GitHub Code de notre fork Télécharger notre build Linux

Nouveau dans la 1.5 : MAME, en second émulateur

Bootcade lance désormais aussi MAME. Ses jeux côtoient vos jeux FinalBurn Neo dans une seule bibliothèque, avec les mêmes profils de manette et les mêmes genres, et le gestionnaire de ROMs vérifie et répare vos sets MAME comme les autres.

MAME est un projet distinct, avec sa propre équipe : installez-le et Bootcade le trouve tout seul. Les classements, le catalogue en ligne et le téléchargement de ROMs ne concernent que FinalBurn Neo pour l'instant.

Pensé pour les collections trop grandes pour un gestionnaire de fichiers

Les scores

Ton score, lu directement dans le jeu

Les jeux classables portent une pastille Highscore. Tu joues, tu quittes, ton score part. Le lanceur compare la table des scores avant et après ta partie : ce qui est publié est donc bien ce que tu as fait, et non les valeurs d'usine dont toute table neuve est remplie.

Gestion des ROMs

Un flux à la RomVault, intégré

Chaque ROM est vérifiée en recalculant son CRC32 face aux fichiers DAT officiels, ceux de FinalBurn Neo comme ceux de MAME : jamais en se fiant à un nom de fichier ni à la valeur stockée dans l'archive.

  • Audit d'intégrité des ROMs via vérification CRC des DAT
  • Détecte les ROMs manquantes, corrompues ou incomplètes
  • Reconstruit les sets automatiquement depuis votre bibliothèque existante
  • Import récursif des ROMs
  • Génère des rapports de ROMs manquantes et d'audit
  • Affiche les infos clone / parent directement depuis le DAT
  • Trouve les ROMs en double dans votre bibliothèque
  • Chaque set est vérifié avant d'atterrir dans la sortie

📀

Vraie vérification CRC

Chaque entrée de chaque archive est décompressée et son CRC32 recalculé, puis confronté au DAT. Une archive corrompue ne peut pas se faire passer pour valide.

🔬

Audit de la bibliothèque

Vous dit quels sets sont cassés et quel fichier est en cause, avec quatre verdicts distincts.

  • OK : bon nom, bonnes données
  • Mal nommé : bonnes données, mauvais nom
  • Corrompu : présent mais contenu erroné
  • Absent : pas dans le set du tout
📥

Reconstruction entrée → sortie

Déposez vos téléchargements dans un dossier d'entrée et lancez Analyser. Les sets complets sont déplacés, les cassés reconstruits à partir de pièces trouvées dans vos téléchargements et dans votre bibliothèque existante.

🛡️

Votre bibliothèque n'est jamais modifiée

Elle ne sert que de réservoir de pièces, en lecture seule. Les résultats atterrissent dans un dossier de sortie séparé qui reproduit l'arborescence des DAT : au pire, un dossier à supprimer.

🗜️

zip, 7z, rar, tar

Lit tout ce que vous avez téléchargé : archives 7z solides comprises, vidées en une seule passe. Écrit toujours des sets ZIP propres et à plat, le seul format que l'émulateur charge.

⚡

Scan incrémental

Une base SQLite locale avec un cache adressé par contenu. Les rescans ne touchent que les fichiers dont la taille ou la date a bougé ; une mise à jour de DAT ne revérifie que les sets réellement modifiés.

📋

Rapports exportables

Enregistrez la liste des ROMs manquantes ou l'audit complet en rapport texte, groupé par système, avec le CRC et la taille de chaque fichier qu'il vous reste à trouver.

⬇️

Télécharger ce qui manque

Après un audit, un set FinalBurn Neo manquant se télécharge depuis le serveur Bootcade en un clic, avec votre compte et son quota quotidien. Il passe par l'Import, qui le vérifie et le range comme n'importe quelle ROM.

🔄

Outils DAT

Générez les fichiers DAT depuis votre binaire FinalBurn Neo ou MAME, récupérez les DAT chez leurs éditeurs, actualisez la base ou téléchargez la dernière version de FBNeo : le tout depuis l'application.

PC de jeu Linux et SteamOS

À sa place dans le salon

Pensé pour les machines de jeu Linux et les systèmes SteamOS du salon : une vraie interface de bureau, pilotée au clavier et à la souris, avec la manette prête pour le jeu lui-même.

🎮

SteamOS et Steam Machine (Steam Box)

SteamOS repose sur Arch avec une partition système en lecture seule : Flatpak y est donc la voie d'installation supportée pour les logiciels de bureau. Le bundle Flatpak s'installe directement en mode Bureau, sans déverrouiller le système ni toucher à pacman.

🕹️

Clavier et souris pour parcourir, manette pour jouer

Chercher parmi 55 000 jeux est un travail de clavier : le lanceur est construit autour de ça. Les jeux démarrent avec le support joystick déjà actif, et les profils de manette sont enregistrés et réutilisés.

📺

Deux clics de la liste au jeu

Pas de menus imbriqués à traverser : cherchez, cliquez, jouez. Ajoutez le lanceur à Steam comme jeu externe et il devient accessible depuis le mode Jeu.

Depuis les sources

Trois commandes sur Debian ou Ubuntu

# 1 : dependencies
sudo apt install -y build-essential cmake pkg-config \
  libgtkmm-3.0-dev libpugixml-dev nlohmann-json3-dev \
  libcurl4-openssl-dev libzip-dev libarchive-dev \
  zlib1g-dev libsqlite3-dev

# 2 : build
git clone https://github.com/battousai90/bootcade-launcher.git
cd bootcade-launcher && cmake -S . -B build && cmake --build build -j$(nproc)

# 3 : run
cd build && ./bootcade

Vous préférez les paquets ? ./scripts/package.sh produit l'AppImage, le .deb, l'archive tar et le bundle Flatpak dans dist/ : exactement le script qu'exécute le workflow de publication.
