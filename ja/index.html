エミュレーター FinalBurn Neo のために

Bootcade はフロントエンドです。ROM セットを見つけ、検証し、整理したうえで FinalBurn Neo に渡し、実際のエミュレーションはそちらが担います。エミュレーターは独自のチームによる別プロジェクトで、本ランチャーから最新版をダウンロードできます。

Linux版ではさらに一歩踏み込んでいます。FinalBurn Neo本家チームはSDL2/Linux版のメンテナンスを終了しており、一部のシステム（Game Boy Advance、Bally Astrocade）ではゲームリストの生成が気づかぬうちに止まっていました。私たちは彼らのリポジトリを毎日追跡し、この修正を加えた独自ビルドを公開しているので、すべてのシステムが最初からカバーされます。

fbneo.com GitHub の FinalBurn Neo フォークのコード Linuxビルドをダウンロード

1.5 の新機能：2 つ目のエミュレーターとして MAME に対応

Bootcade は MAME も起動できるようになりました。MAME のゲームは FinalBurn Neo のゲームと同じライブラリに並び、同じコントローラープロファイルとジャンルが使えます。ROM マネージャーは MAME のセットも他と同じように検証・修復します。

MAME は独自のチームを持つ別プロジェクトです。インストールすれば Bootcade が自動で見つけます。リーダーボード、オンラインカタログ、ROM のダウンロードは今のところ FinalBurn Neo のみ対応です。

29,000 本以上の FinalBurn Neo のゲームをブラウザで

FinalBurn Neo のすべてのシステムを、公式 FBNeo DAT ファイルから直接インデックス化。名前で検索し、システムやリリース種別で絞り込み、セットの DAT やアートワークをダウンロードできます。見るだけならインストール不要です。MAME はまだオンラインカタログにありません。

カタログを見る

スコア

ゲーム本体から読み取った、あなたのスコア

プレイを終えると、ランチャーがゲームの実際にメモリへ書き込んだ内容を読み取ります。数字を打ち込む必要も、スクリーンショットを送る必要もありません。ランチャーからでも Web カタログからでも、みんなと競えます。

🏆

何もしなくていい

ランキング対応のゲームには Highscore のバッジが付きます。遊んで終了すれば、それだけでスコアが送られます。ランチャーはプレイ前後のスコア表を比べるので、公開されるのはあなたが出した記録であり、新品の表に最初から入っている工場出荷値ではありません。

⏱️

ゲームごとのプレイ時間

前回のプレイ、最長のプレイ、そして累計を、ゲームごとに記録します。再構築されたカタログではほとんどが失われるなか、DAT の更新をまたいでも残ります。

🥇

解除できる 24 の実績

スコアとプレイ時間で実績が解除され、プロフィールに表示されます。最初のスコアから 100 本の異なるゲームまで、遊びながら集める 18 の実績と、複数のプレイヤーが競うランキングで獲得する 6 つのプレステージ実績です。プレステージ実績を 3 つ獲得すると、ROM ダウンロードのチャンピオン枠が開放されます。

🔒

あなたが許可するまではオフ

署名する名前と明確な同意がなければ、何も送信されません。スコアの送信はプレイ時間も公開することになり、それはゲームというより生活の習慣に関わる情報だからです。オフラインではスコアを保存し、あとで送信します。失われることはありません。

リーダーボード

ROM 管理

RomVault 風のワークフローを内蔵

すべての ROM は、FinalBurn Neo と MAME の公式 DAT ファイルに対して CRC32 を再計算して検証されます。ファイル名やアーカイブに保存された値を信用することはありません。

  • DAT の CRC 照合で ROM の整合性を監査
  • 不足・破損・不完全な ROM を検出
  • 既存のライブラリからセットを自動的に再構築
  • ROM を再帰的にインポート
  • 不足 ROM レポートと監査レポートを生成
  • クローン / 親情報を DAT からそのまま表示
  • ライブラリ内の重複 ROM を検出
  • 出力に入る前にすべてのセットを検証

📀

本物の CRC 検証

すべての書庫のすべてのエントリーを展開して CRC32 を再計算し、DAT と照合します。破損した書庫が正常を装うことはできません。

🔬

ライブラリ監査

どのセットが壊れていてどのファイルが原因かを、4 つの明確な判定で示します。

  • OK : 名前もデータも正しい
  • 名前違い : データは正しいが名前が違う
  • 破損 : 存在するが内容が誤り
  • 欠落 : セットに存在しない
📥

受信箱 → 送信箱の再構築

ダウンロードを受信フォルダーに置いて「解析」を押すだけ。完全なセットは移動され、壊れたセットはダウンロード内および既存ライブラリ内で見つかった部品から再構築されます。

🛡️

ライブラリには一切書き込みません

ライブラリは読み取り専用の部品置き場としてのみ使われます。結果は DAT の構成を写した別の出力フォルダーに置かれるので、最悪でも削除すれば済みます。

🗜️

zip・7z・rar・tar

ダウンロードしたものをそのまま読み込みます。ソリッド圧縮の 7z も一度の走査で取り出します。書き出しは常にフラットでクリーンな ZIP セット : エミュレーターが読める唯一の形式です。

⚡

差分スキャン

内容アドレス方式のキャッシュを備えたローカル SQLite データベース。再スキャンはサイズや更新日時が変わったファイルのみを対象とし、DAT 更新時も実際に変わったセットだけを再確認します。

📋

書き出せるレポート

不足 ROM の一覧や監査結果をシステム別に整理したテキストレポートとして保存。まだ必要なファイルの CRC とサイズも記載されます。

⬇️

足りないものをダウンロード

監査のあと、不足している FinalBurn Neo のセットを、あなたのアカウントと 1 日の上限で Bootcade サーバーからワンクリックでダウンロードできます。インポートを通り、ほかの ROM と同じように検証・整理されます。

🔄

DAT ツール

FinalBurn Neo または MAME のバイナリから DAT ファイルを生成し、DAT を配布元から取得し、データベースを更新し、最新の FBNeo をダウンロード。すべてアプリ内で完結します。

Linux ゲーミング PC と SteamOS

リビングにもなじむ

Linux のゲーミングマシンと、ソファの前の SteamOS 機のために作られています。キーボードとマウスで操作する本物のデスクトップ画面、そしてゲーム本体にはコントローラーを。

🎮

SteamOS と Steam Machine（Steam Box）

SteamOS は Arch ベースでシステム領域が読み取り専用のため、デスクトップソフトの導入方法として Flatpak が正式にサポートされています。Flatpak バンドルはデスクトップモードにそのまま導入でき、システムのロック解除も pacman も不要です。

🕹️

探すのはキーボードとマウス、遊ぶのはパッド

55,000 本から探すのはキーボードの仕事です。ランチャーはそれを前提に作られています。ゲームはジョイスティック対応を有効にした状態で起動し、コントローラープロファイルは保存して再利用できます。

📺

一覧からゲームまで 2 クリック

入れ子のメニューをかき分ける必要はありません。検索し、クリックし、遊ぶだけ。Steam に非 Steam ゲームとして追加すれば、ゲームモードからも起動できます。

Download for Windows

AppImage をダウンロードしたら： chmod +x bootcade-*.AppImage && ./bootcade-*.AppImage
.deb の場合： sudo apt install ./bootcade_*.deb
エミュレーター本体も必要です。ランチャーは設定画面から最新の FinalBurn Neo をダウンロードでき、MAME はディストリビューションのパッケージからインストールすれば自動で見つけます。

ソースから

Debian / Ubuntu なら 3 コマンド

# 1 : dependencies
sudo apt install -y build-essential cmake pkg-config \
  libgtkmm-3.0-dev libpugixml-dev nlohmann-json3-dev \
  libcurl4-openssl-dev libzip-dev libarchive-dev \
  zlib1g-dev libsqlite3-dev

# 2 : build
git clone https://github.com/battousai90/bootcade-launcher.git
cd bootcade-launcher && cmake -S . -B build && cmake --build build -j$(nproc)

# 3 : run
cd build && ./bootcade

パッケージが欲しいですか？ ./scripts/package.sh が AppImage・.deb・tar アーカイブ・Flatpak バンドルを dist/ に生成します。リリースワークフローが実行するのとまったく同じスクリプトです。
